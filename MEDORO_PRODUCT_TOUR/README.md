# MEDORO_PRODUCT_TOUR

Hindi-English product tour of Medoro Pharmacy, recorded on a separate demo server with a fictional demo pharmacy.

- `01_…25_*` – videos (MP4, in the session workspace; not committed to git because of size) with matching SRT subtitles. Compilations are named `V01_…` to `V12_…`; individual parts are `Part_NN_…`. Each compilation has a `_chapters.txt` with timestamps.
- `26_Scripts_Subtitles` – narration scripts for all 26 parts (spoken Hindi + Hinglish subtitles), every SRT, and video titles, descriptions and chapter timestamps.
- `27_Thumbnails` – 1920×1080 thumbnails for all 38 videos.
- `28_QA_Report` – environment, demo data, bugs found and fixed, feature status, recording QA.
