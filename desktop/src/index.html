Medoro

Enter the address of your pharmacy’s Medoro server. Your IT person or the owner’s setup screen shows it, for example https://medoro.shop.local.

On a Mac, offline billing works only in a browser: open your Medoro server in Chrome or Edge and install it from the address bar (Install Medoro). This app needs the server to be reachable.

Medoro keeps your data on your server. This app stores only the server address on this computer.
